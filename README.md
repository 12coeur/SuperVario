    • Partage : Le ratio de mixage entre la pression et l'accéléromètre.
    • Cadence : La cadence de la boucle principale de traitement (en millisecondes). 
    • Largeur : La largeur d'affichage du vario (en pourcentage). 
    • Hauteur : La hauteur d'affichage du vario (en pourcentage). 
    • Alpha : Le niveau d'opacité de l'interface. 
    • Amplitude : L'amplitude de déplacement de l'aiguille. 
    • Volume : Le volume global de l'audio. 
    • SonAigu : Le réglage de tonalité/vitesse pour les sons aigus. 
    • SonGraves : Le réglage de tonalité/vitesse pour les sons graves. 
    • SeuilMonte : Le seuil minimal de déclenchement en montée (en m/s). 
    • SeuilBaisse : Le seuil minimal de déclenchement en baisse (en m/s). 
    • GainP : Le multiplicateur de gain pour la pression. 
    • GainA : Le multiplicateur de gain pour l'accéléromètre. 
    • Amortissement : Le niveau d'amortissement de l'accélération. 
    • LissageP : Le coefficient de lissage appliqué aux variations de pression. 
    • StopAccel : L'état d'arrêt (activé ou désactivé) de l'accéléromètre. 
    • StopPression : L'état d'arrêt (activé ou désactivé) du baromètre. 
    • AccelRefuse : L'indicateur du refus persistant de l'accéléromètre. 
    • SonMonte : Le fichier audio WAV sélectionné pour la montée (ex: M2). 
    • SonBaisse : Le fichier audio WAV sélectionné pour la baisse (ex: B4).
